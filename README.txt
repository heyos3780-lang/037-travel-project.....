เว็บไซต์เที่ยวบ้านเรา — งาน HTML/CSS/JavaScript

เปิด index.html ในเบราว์เซอร์เพื่อดูเว็บ
ไฟล์เว็บ: index.html, places.html, food.html, plan.html, travel.html, login.html
style.css เป็นไฟล์ตกแต่ง, images/ เป็นภาพจากไฟล์ที่ครูให้
หน้าเข้าสู่ระบบเป็นตัวอย่างการตรวจแบบฟอร์มฝั่งเบราว์เซอร์ ไม่ใช่การเข้าสู่ระบบจริง

อัปโหลดไฟล์ทั้งหมดรวมทั้งโฟลเดอร์ images ไปยัง GitHub repository แล้วเปิด Settings > Pages > Deploy from a branch > main / (root)
หมายเหตุ: ไฟล์ต้นฉบับของครูไม่ถูกแก้ไข; นี่เป็นสำเนาที่พัฒนาเพิ่มเติม

เพิ่มหน้า register.html และ auth.js (ระบบสมัคร/เข้าสู่ระบบสาธิต)
วิธีทดลอง: เปิด register.html สมัครสมาชิก จากนั้นเปิด login.html เข้าสู่ระบบ
ระบบนี้เก็บข้อมูลใน localStorage ของเบราว์เซอร์ และสถานะล็อกอินใน sessionStorage
รหัสผ่านเก็บเป็น SHA-256 พร้อม salt เพื่อสาธิตเท่านั้น ไม่เหมาะสำหรับงานจริง
อย่าใช้รหัสผ่านจริง เบราว์เซอร์หรืออุปกรณ์อื่นจะไม่เห็นบัญชีที่สร้างไว้
